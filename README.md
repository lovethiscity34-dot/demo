# Horus Super Win 1000

Demo slot HTML/CSS/JavaScript bertema Horus dari mitologi Mesir Kuno.

## Fitur
- 6 reel × 5 baris
- Sistem tumble/cascade
- Scatter & free spins
- Turbo
- Main otomatis
- Beli free spin (virtual)
- Paytable
- Riwayat kemenangan
- UI responsif desktop/tablet/mobile
- Semua aset visual dibuat sebagai SVG inline — tidak membutuhkan CDN atau asset eksternal
- Kredit awal Rp 100.000
- Jika kredit < Rp 10.000, demo otomatis mengisi kembali menjadi Rp 100.000

## Menjalankan
Cukup buka `index.html` di browser.

## GitHub Pages
1. Buat repository baru, misalnya `horus-super-win-1000`.
2. Upload `index.html` dan `README.md`.
3. Buka **Settings → Pages**.
4. Pilih deploy dari branch utama (`main`) dan folder `/root`.
5. Simpan. GitHub Pages akan memberi URL gratis untuk game.

## Catatan
Ini hanya game demo dengan kredit virtual. Tidak ada transaksi uang nyata, deposit, withdraw, atau hadiah uang.
